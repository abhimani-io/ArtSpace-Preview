# 🎨 ArtSpace Preview

An AR-Assisted Art Visualization and Marketplace Mobile Application built with Flutter and Firebase.

---

## 🚀 Features 
* **User Authentication:** Secure signup and login using Firebase Auth.
* **AR Art Preview:** Visualizing artwork in real-world environments using AR technology.
* **Real-time Marketplace:** Browse, list, and manage artwork with instant Firestore updates.
* **Responsive UI/UX:** Clean and modern look tailored for art enthusiasts.

## 🛠️ Tech Stack 
* **Frontend Framework:** Flutter (Dart)
* **Backend & Database:** Firebase Auth, Cloud Firestore
* **State Management:** Provider / setState
